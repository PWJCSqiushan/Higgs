# M5：说话意愿与主动性

## 没被 @ 时要不要接话（Interest Gate）

在 `R_AGENT_INTEREST_GROUPS`（默认是所有回复群）里，一条没有 @ Higgs、也没有触发词的群消息，会依次经过三步：

1. **算一个接话概率。** 用逻辑回归按下表的特征打分（这套特征参考了 MaiBot 公开的设计，代码是独立实现的；权重先手工设定，以后用 Higgs 自己的日志重新拟合）。

   | 特征 | 对接话概率的影响 |
   | --- | --- |
   | 提到 Higgs/希格斯 | 显著升高 |
   | 问句（问号、"吗"、"怎么"等） | 升高 |
   | 最近 20 条里 Higgs 发言占比高（正在聊） | 升高 |
   | 待处理消息多 | 略升高 |
   | 消息在 @ 别人 | 降低 |
   | 只有图片或表情 | 降低 |
   | 距 Higgs 上次说话越久 | 降低 |

2. **乘以频率、抽签。** 概率乘以 `R_AGENT_INTEREST_FREQUENCY` 后随机抽签。另有硬上限：每小时 6 次、每天 30 次、两次之间至少隔 90 秒，都可配置。
3. **交给模型决定怎么接。** 抽中后，这条消息会被标记为"插话"。模型可以：
   - 正常短句接话；
   - 只输出 `SKIP`：不说话；
   - 只输出 `REACT`：给原消息点一个"赞"表情（NapCat `set_msg_emoji_like`，表情 ID 76）。

`SKIP` 和 `REACT` 会释放预占的发送预算，在审计中分别记为 `skipped` / `reacted`。

## 冷场时主动开话题（ProactiveChatter）

只在 `R_AGENT_PROACTIVE_GROUPS` 列出的群里生效（默认关闭）。每 20 分钟左右（带随机抖动）检查一次，同时满足以下条件才可能开口：
- 处于活跃时段；
- 群里已安静 ≥ `IDLE_MINUTES`；
- 最后一条不是 Higgs 自己说的；
- 当天还没达到上限（默认每群每天 3 次）；
- 随机抽签通过（概率 0.35）。

模型会参考最近的群聊和 M4 的心情/日记，写一两句话；不合适就输出 `SKIP`。这类消息走 risk ledger 的 `proactive` 预算，发出后写入群时间线。

## 拟人小动作

私聊回复前，会先调用 NapCat `set_input_status`，让对方看到"对方正在输入"。

验证：`tests/test_willingness.py` 覆盖概率形状、上限与作用域、主动开话题（发送、写入时间线、上一条是自己时静默、每日上限、活跃时段）、SKIP；端到端场景中，三条未 @ 的群消息分别得到真实回复、表情回应和沉默，私聊时触发"正在输入"。
