# 安全边界

## 凭据

本项目永不需要 QQ 密码或手机号。QQ 登录由独立的 NapCat 进程通过扫码完成。本项目只接收：

- loopback OneBot WebSocket 地址；
- 随机生成的 OneBot access token；
- 人类 owner 的 QQ 号；
- 明确获准的测试群号。

以上真实值只能放在未纳入 Git 的本地环境或 secrets 文件中。

如果凭据曾经出现在聊天、截图、终端历史或日志中，应视为已经暴露并立即轮换。

## Phase 1 不变量

- 不发送任何 OneBot action。
- 不调用 LLM。
- 不执行工具。
- 不建立长期记忆。
- owner 未配置时不接收任何私聊。
- 群白名单为空时不接收任何群聊。
- 非 loopback OneBot 地址拒绝启动。
- 日志不记录消息正文、QQ 号、token 或原始事件。

## 数据最小化

Journal 只保存规范化文本、必要路由字段和不含 URL 的附件类型/文件名。默认保留七天，最大允许配置为三十天。后续真实测试前还需要实现按主体删除与加密备份。
