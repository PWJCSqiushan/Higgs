# M4：内心生活

| 部分 | 怎么形成 | 用在哪里 |
| --- | --- | --- |
| **对人的印象** | 每 60 分钟读取各群新增的时间线，为本时段发言 ≥3 次的人写或更新一句不超过 60 字的印象（性格、兴趣、说话方式、和 Higgs 的关系），并融合旧印象 | 在同一个群里回复时，注入"当前发言人 + 最近活跃的 4 人"的印象 |
| **心情** | 每晚写日记时一并给出：标签、愉悦度 −1..1、精力 0..1、一句话 | 每轮对话的"你最近的心情与想法" |
| **日记与反思** | 每天 `R_AGENT_INNER_DIARY_TIME`（默认 23:30）写一次：素材是 Higgs 当天在群里说过的话、当天的说说、此前的心情和上一篇日记；产出 150–400 字日记和 1–3 条反思 | 注入最近一篇日记的摘要和反思；同时作为 QQ 空间起草的素材 |

## 安全与隐私

- **印象：** 按群隔离，只在对应的群里注入。以 `sha256(bot, 群, QQ)` 作为键，库里不存原始 QQ 号。模型只能更新"需要更新的人"名单里列出的标签。含隐私词（手机号、住址、身份证、工资、病等）或没通过敏感词过滤的印象会被丢弃。
- **日记和反思：** 经过同样的过滤，每条都有长度上限。
- **注入方式：** 所有内容都以"你自己的看法/内心"的身份注入，并要求不要原样复述给对方。

## 主人命令

- `/higgs inner`：查看心情、最近一篇日记和印象数量。
- `/higgs inner diary`：看最近 3 篇日记。
- `/higgs inner reflect`：立即更新印象并重写今天的日记。
- `/higgs inner impressions <群号>`：查看对某个群里各人的印象。
- `/higgs inner forget <标签>`：删除对某人的印象。

`ContextBuilder` 新增 `context_providers`，QQ 空间（M3）和内心生活（M4）都通过它注入。单个 provider 出错时直接跳过，不影响这次回复。
