# M6：看图、多气泡与总览

## 多气泡

模型可以用 `[MSG_BREAK]` 把一条回复拆成最多 3 条短消息：
- 第一条照常带 M1 的引用和 @；
- 后续每条间隔 0.6–2 秒发出；
- 单条超过 1500 字时，会在换行或句号处自动拆开；
- 写入群时间线前会去掉 `[MSG_BREAK]` 标记。

用 `R_AGENT_BUBBLES_ENABLED=false` 关闭后，标记会被替换成换行，所有内容合成一条发送。

## 看图（默认关闭）

`R_AGENT_VISION_ENABLED=true` 后，按以下流程处理图片：
1. 只处理即将回复的消息（被 @ 或被判定插话的消息），每条最多 2 张图。
2. 用只允许公网 IP 的 `SafeNetworkClient` 下载图片。只接受 `https://` 链接和 image/* 类型，单张上限 4 MiB。
3. 交给视觉模型（默认 `glm-4v-flash`），生成不超过 40 字的描述。
4. 描述写成 `[图片：…]`，同时写进模型看到的消息和群时间线。

图片 URL 只在内存里用于这一步，不进入 journal 或任何队列。开启这项后，图片内容会发给视觉模型的提供方，这是一个需要主人决定的隐私边界，所以默认关闭。每天调用上限由 `R_AGENT_VISION_DAILY_LIMIT` 控制。

## `/higgs overview`

主人命令。一屏列出 3.0 各项能力的开关和关键状态：
- 群时间线：开关和 24 小时内活跃的群数
- 工具：已注册的工具和最近的调用
- QQ 空间：发布模式、刷动态开关
- 内心生活：当前心情、印象条数
- 插话和主动开话题：开关和生效的群数
- 多气泡、看图：开关
