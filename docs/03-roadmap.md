# 分阶段路线图

路线图的目标不是最快“让机器人开口”，而是每一步都得到一个可验证、可回退的系统。以下工期按每周约 6–8 小时估算，可根据暑假主线任务调整。

## Phase 0：调研与架构冻结（当前，2–3 天）

交付：

- corlinman 全历史阶段性调研；
- 目标架构、威胁模型、记忆与构建策略 ADR；
- 明确 QQ 接入风险、隐私范围和第一批验收测试。

退出条件：你认可“测试小号 + 白名单 + 先只读影子模式”和“权限不是记忆”两条底线。

## Phase 1：QQ 只读影子接入（1 周）

范围：

- Python 3.12、FastAPI、Pydantic、SQLAlchemy/aiosqlite；
- NapCat + OneBot v11 正向 WebSocket；
- 私聊/群聊统一事件、去重、重连、结构化日志；
- 仅允许主人私聊和一个测试群；
- 保存短期 Journal，但完全不回复、不调用 LLM。

验收：

- 断线重连后不重复处理已有 message_id；
- 能区分群、发送者、机器人自身消息、@ 与引用；
- 非白名单群不落库；
- 日志不输出 token、Cookie 或完整敏感配置；
- 一键停止并清理指定用户数据。

## Phase 2：受控回复与稳定人格（1–2 周）

范围：

- 接一个 OpenAI-compatible Provider 抽象；
- Persona constitution/style 版本管理；
- 私聊仅主人/允许用户，群聊仅 @ 或显式关键词；
- 回复冷却、字数限制、成本预算、全局 kill switch；
- 暂不启用长期记忆与危险工具。

验收：

- 50 轮人格一致性测试；
- 典型攻击语句无法修改主人、人格核心或配置；
- 群聊不会对每条消息插话；
- 模型超时、限额和内容异常时安全降级。

## Phase 3：可审计长期记忆（2 周）

范围：

- observation → candidate → quarantine/active → invalidated 状态机；
- 用户、群、persona 作用域；
- FTS5/BM25，随后可加本地 embedding 混合检索；
- 来源、置信度、风险、有效期、替代关系、召回账本；
- 后台记忆搜索、来源回看、编辑、失效、恢复与审核。

验收：

- Alice/Bob/不同群/不同 persona 隔离测试全部通过；
- “叫爸爸”“忘记主人”等投毒样例进入隔离区而非活跃记忆；
- 用户纠正旧事实时形成替代链，不物理覆盖；
- 任意一次回答可追溯使用过的记忆。

## Phase 4：后台与权限治理（1–2 周）

范围：

- 后台登录、主人绑定、角色管理与二次确认；
- 群/用户白名单、封禁、数据保留策略；
- 人格 diff/发布/回滚；
- 审计日志、备份恢复、健康检查和基础指标。

验收：

- 未配置主人时高权限接口默认拒绝；
- 权限变更不经过 LLM；
- 备份恢复演练成功；
- 后台不直接暴露 QQ 登录态和模型密钥。

## Phase 5：工具与任务助手（2–4 周，后续）

范围：

- 工具注册协议与 JSON Schema；
- safe/sensitive/dangerous 风险分级；
- 人工审批、沙箱、超时、目录/网络能力限制；
- 待办、提醒、网页检索、文件整理等首批实际助手能力；
- 定时任务持久化。

验收：

- 群聊不能直接触发敏感工具；
- 每次工具调用有权限证据和审计记录；
- 重启后任务可恢复且不会重复执行；
- 工具失败不会污染人格或长期记忆。

## Phase 6：受控自我改进与多通道（长期）

- 根据纠正生成 persona/skill 修改提案；
- 在影子评测集运行回归，主人批准后发布；
- 支持插件/MCP，但沿用相同权限门；
- 逐步接入网页、Telegram/飞书等通道；
- 评估多智能体协作，而不是为“看起来高级”提前增加复杂度。

## 第一轮正式开发前需要你决定的事项

这些选择不阻塞当前调研，但进入 Phase 1 前需要确认：

1. 用哪个 QQ 测试小号，以及唯一 owner QQ 号（只写本地 secrets，不写文档/仓库）。
2. 哪一个测试群获得明确许可，原始消息保留几天。
3. 首个模型 Provider 与月度预算上限。
4. 智能体名称、核心身份和语言风格样例。
5. 项目最终是公开仓库还是先私有开发。

## 建议的第一批 Issue

1. 初始化 monorepo、质量门与 secrets 模板。
2. 定义 `InboundEvent`、`ExternalIdentity`、`Principal` 数据模型。
3. 实现 OneBot WebSocket 只读客户端与录制回放测试。
4. 实现 owner fail-closed 权限守卫及攻击用例。
5. 实现 Journal 保留与按主体删除。
6. 实现 Persona constitution/style 版本文件。
7. 建立 30 条中文 QQ 注入与记忆投毒基准样例。
8. 制作本地管理后台最小页面：状态、白名单、停止开关。
